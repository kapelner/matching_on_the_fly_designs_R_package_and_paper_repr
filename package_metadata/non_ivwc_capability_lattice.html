Notes

  • ¹ InferenceAsympLik itself has no fixed default for supports_likelihood_tests — it's an abstract dispatch point; every concrete/near-abstract descendant sets it explicitly (or inherits a default from one of the backbone classes below it, e.g. InferenceCountLikelihood defaults it to TRUE).
  • ² "OneLik" naming-convention break: these four classes (continuous + proportion quantile-regression "OneLik", continuous robust-regression "OneLik") are named like the full-capability branch established by Cox/Copula/Frailty/CondLogit/OLS in the first lattice, but actually inherit InferenceKKPassThroughCompoundNoParamBootstrap — zero likelihood-test capability.
  • ³ use_rcpp-gated: 8 classes drop to Wald-only whenever the pure-R fallback path is used instead of the Rcpp backend (same pattern as Weibull-frailty in the first lattice): InferenceContinKKGLMM, InferenceCountKKGLMM, InferenceOrdinalKKGLMM, InferenceSurvivalCoxPHRegr, InferenceSurvivalStratCoxPHRegr, and the Hurdle-Poisson/ZIP/ZINB zero-augmented family (whose flag is technically use_rcpp AND description-match, but every concrete daughter's description matches, so it reduces to use_rcpp in practice).
  • ⁴ Terminology collision: "partial" in InferenceOrdinalPartialProportionalOdds names the partial proportional odds statistical model, unrelated to "partial likelihood" — and the class sits outside the InferenceAsympLik subtree entirely regardless.
  • ⁵ Dead flag: InferenceSurvivalKKWeibullMarginal sets supports_likelihood_tests = FALSE while inheriting InferenceAsymp directly — the flag is defined but never consulted by any dispatch, the same "inert override" shape as Weibull-frailty-IVWC's conditional flag in the first lattice.

Reinforcing the lattice-not-chain point: the "inside InferenceParamBootstrap's static chain, yet flagged to zero capability" pattern (first seen with quasi-Poisson/robust-Poisson) recurs on a much larger group here: InferenceAllSimpleMeanDiff/PooledVar, InferenceAllSimpleWilcox, InferenceIncidWald, InferenceIncidCMH/ExtendedRobins, the KK-Marginal g-comp family, InferencePropFractionalLogit, InferenceIncidRiskDiff, and non-KK InferenceIncidModifiedPoisson. Meanwhile InferenceAsympLikStdModCache — not InferenceKKPassThroughCompound — turns out to be the single largest branch in the package, hosting essentially every non-KK GLM-style family.
